# 🎬 Movie Genre Classification using Machine Learning

## 📖 Overview
This project is a Machine Learning–based web application that predicts the genre of a movie from its plot description. The model uses Natural Language Processing (NLP) techniques with TF-IDF vectorization to convert text into numerical features and classify the movie into its most likely genre.

## ✨ Key Features
- ● Predicts movie genres from plot descriptions
- ● NLP-based text preprocessing using TF-IDF Vectorizer
- ● Machine Learning classification model
- ● Interactive Streamlit web interface
- ● Fast and user-friendly prediction system

## 🛠️ Technologies Used
- ● Python
- ● Streamlit
- ● Scikit-learn
- ● Pandas
- ● Joblib
- ● TF-IDF Vectorizer

## 📂 Project Structure
- ● app.py – Streamlit application
- ● model.pkl – Trained Machine Learning model
- ● vectorizer.pkl – Saved TF-IDF vectorizer
- ● requirements.txt – Project dependencies
- ● README.md – Project documentation

## 🚀 How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🎯 Project Outcome
- ● Successfully classifies movie genres based on plot descriptions.
- ● Demonstrates the integration of Machine Learning, NLP, and Streamlit into a deployable web application.
- ● Suitable for academic projects, portfolio demonstrations, and Machine Learning practice.
